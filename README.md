Root Solver is a Python project for exploring and comparing two numerical methods used to approximate roots of equations.

Methods

Bisection method

Newton's method

Features

Searches for a valid interval for a bisection

Uses a tolerance to stop when the approximation is accurate enough

Tracks iteration counts

Handles cases where Newton's method encounters a zero derivative

Limits searches and iterations to avoid infinite loops

Tests successful cases and failure cases

What I Learned

This project helped me understand how numerical methods behave in practice, including convergence, tolerance, starting values, and failure conditions.

Status

The comparison and analysis of the two methods has been completed and I have written a comparative report.
